# Skill: launch-checklist

**Reads:** everything else in `gtm/`.
**Output:** `gtm/out/launch-checklist.md`.

Produce a checklist for a human: the Connect app made with `pnpm connect`
and its ask matching `connect.manifest.json`; sign-in tested end to end on
a real account; each built-in profile the launch claims run once on a
real grant (flip `verified` to `real` only then); `pnpm start` exits 0
from a clean clone; README quickstart checked; a privacy page; the
domain; a first-ten-users plan from `gtm/out/creator-outreach.md` and
`gtm/out/launch-post.md`.

Draft only. This skill writes the list; it does not run any of it.

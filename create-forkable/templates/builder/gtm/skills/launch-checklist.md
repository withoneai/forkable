# Skill: launch-checklist

**Reads:** everything else in `gtm/`.
**Output:** `gtm/out/launch-checklist.md`.

Produce a checklist for a human: a generated app with its own Connect app,
signed in end to end on a real account; a real action called on a real
grant; a real GitHub export and Vercel deploy from the Publish dialog;
`pnpm start` exits 0 from a clean clone; README quickstart checked; a
privacy page; the domain; a first-ten-users plan from
`gtm/out/creator-outreach.md` and `gtm/out/launch-post.md`.

Draft only. This skill writes the list; it does not run any of it.

**Reads:** `local/profile.md`, `README.md`, `packages/template/_AGENTS.md`
(what a generated app can do), the output of `pnpm start`.
**Output:** `gtm/positioning.md`.

Ask (or infer from the files above) who this fork is for, the problem
(what stops them shipping the app they want), the one-line promise and the
proof: one prompt that turns into a working app. Run it for real so the
proof is real. Write the four fields into `gtm/positioning.md`. Run this
before any other GTM skill.

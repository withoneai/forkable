# Positioning

Filled in by `gtm/skills/positioning.md`. Every other GTM skill reads this
file first. The lines below are Builder's own starting point; a fork
should rewrite them for the people in `local/profile.md`.

- **Who it's for:** people who already pay for a coding agent and want to
  ship small working apps, without renting a builder that charges by the
  credit.
- **The problem:** an agent can write an app, but sign-in, integrations and
  publishing are where the afternoon goes.
- **The promise:** describe an app, watch your own agent build it, and it
  comes with Sign in with One and its integrations already in place.
- **The proof:** `pnpm start` builds an Acme Inc task list, fixes its own
  type error, restores a checkpoint, adds a Gmail action from One's catalog
  and publishes to a stub, with no keys and no network.

Until a fork rewrites these, GTM skills should ask before reusing them.
